# 采集卡控制上位机 V6

我们基于 Qt 6.8.3 开发了 Windows 上位机，配套 FPGA 采集工程使用。上位机通过已实现的控制 UDP 56556 端口和数据 UDP 端口完成配置、接收与显示。

## 功能

- 广播发现设备、选择当前设备、查询设备/Flash/运行状态。
- 读取、应用、保存与恢复网络、采样率、通道掩码、数据端口和每包组数配置。
- 支持 250 / 500 / 1000 kSPS，24 位通道掩码，1～30 组每包。
- 通过高优先级 WinSock 收包线程与独立数据处理线程实时校验 UDP 数据。二者之间使用预分配的 65536 包 SPSC 队列，收包不受波形绘制与历史计算阻塞。
- 实时显示每通道最近一次采样的电压；电压固定按当前AD7606C的±10 V量程换算。
- 在“实时监测”采集开始前勾选“保存本次采集数据”并选择 `.txt` 路径，可记录全部24路的有符号码值及换算电压；每路各有 `_code` 和 `_V` 两列，字段以制表符分隔，文件还包含包序号、样本序号和微秒时间。可用记事本查看，也可导入 Excel。记录要求当前生效配置已启用全部24路；写盘在独立线程完成，运行中写入临时文件，停止采集并收尾后才生成所选最终TXT。未勾选可直接采集而不保存。
- 显示固定近10分钟的最小、最大和峰峰值（码值及电压），并以 1 ms 至 30 分钟的真实采样时间轴同时观察最多24个勾选通道的滚动波形包络。最近 5 秒采用 50 μs 高分辨率包络，便于观察 kHz 信号；工具栏“横轴 + / −”或鼠标悬停在波形上的滚轮均可缩放横轴。
- 状态栏分别显示接收包数、已处理包数、近1秒/平均/理论包率、接收端 SeqNum 丢失、队列深度、队列溢出、格式错误和 Socket 缓冲区大小。接收端丢失与本机处理队列溢出严格区分。
- 在任一波形区域按住左键水平拖拽，可将所有勾选通道固定到同一历史采样时间窗；“回到最新”恢复实时跟随。最近 5 秒以前的历史以 10 ms 峰值包络显示，并明确标记为历史包络。
- 软件“开始采集”先绑定本机数据UDP端口，再经控制UDP发送START；软件“停止采集”经控制UDP发送STOP，并在FPGA回到READY后的短暂静默窗口结束监测。SW1/SW2与软件命令采用“或”关系，任一来源均可控制，STOP优先。

## 构建

在发布仓库根目录打开 PowerShell，设置 Qt、MinGW 的实际安装目录，并保证 CMake、Ninja 位于 PATH。执行：

```powershell
$env:QT_ROOT='D:\Qt\6.8.3\mingw_64'
$env:MINGW_BIN='D:\Qt\Tools\Tools\mingw1310_64\bin'
powershell -ExecutionPolicy Bypass -File ./build/build_qt.ps1
powershell -ExecutionPolicy Bypass -File ./build/deploy_qt.ps1
```

构建脚本支持 `-QtRoot`、`-MingwBin`、`-Cmake`、`-Ninja` 参数，不必修改源码中的路径。CMakeLists.txt 在 build_output 内由发布的 qt/cmakelists.txt 生成。脚本会运行协议、控制客户端和监测数学测试程序。新构建的便携发布目录为：

```text
build_output/qt_portable
```

可将该目录整体复制到未安装 Qt 的 Windows 电脑上运行。完整提交压缩包的 board/qt_portable 另行保留团队原来的最终 TXT 版程序及其运行库；公开 Git 仓库的同目录只含自有 EXE。历史工作区脚本放在 reference/qt/，正式复现使用 build/ 中的脚本。

## 使用流程

1. 将电脑有线网卡配置到 FPGA 同一网段，例如 `192.168.0.3/24`；确认链路为1 Gbps。
2. 启动软件，在“设备发现”选择对应的电脑网卡IP，广播地址默认为`192.168.0.255`。
3. 点击“广播发现”，从表格选择 FPGA；或手工填写当前设备IP。
4. 在“配置与状态”点击“读取当前配置”。修改参数后点击“应用配置”；界面会自动确认 FPGA 实际应用后的配置。
5. 需要掉电保持时，确认 FPGA 为 READY，再点击“保存到Flash”。SAVE 可能持续约10秒。
6. 如需保存，在“实时监测”采集开始前勾选“保存本次采集数据”并选择TXT文件路径；不勾选则不会保存。勾选需要显示的通道（可全选24路）、选择时间范围，再点击“开始采集”。“横轴 + / −”或悬停在波形上的鼠标滚轮可缩放为最近 1 ms 至 30 分钟；对于 1 kHz 正弦波，建议选择 10 ms 或 20 ms。
7. 要查看固定历史波形，在任一通道图中按住左键向左拖动；所有勾选通道会按同一采样时间锚点同步回看。松开后窗口保持固定，统计仍持续更新；点击“回到最新”恢复右端为当前时刻的实时滚动。
8. 最近 5 秒内可查看 50 μs 高分辨率包络；更早历史显示“历史包络（10 ms）”，不用于逐周期信号判读。
9. “实时电压”是最新有效采样值；“近10分”统计仅针对最近十分钟的有效接收样本。点击“停止采集”或按SW2均可停止；软件会等FPGA完成当前帧、清FIFO并回到READY后再关闭本机接收，统计和波形会保留。若已预选保存，最终TXT会在接收停止并完成收尾后出现，包含每路码值与电压；运行期间可以查看记录行数和队列溢出。

## 注意事项

- 数据目标IP应填写当前运行软件的电脑网卡IP，数据端口需与监测页监听端口一致。
- 当正在采集、停止收尾或 FPGA 报错时，配置按钮会禁用；应先点击“停止采集”或按SW2，等待 FPGA 返回 READY。
- 应用配置的响应由旧地址发送，之后 FPGA 才切换新IP。软件会自动按旧IP、新IP的顺序确认；若仍无法定位，请回到设备发现页广播DISCOVER。
- 同一时间不要运行 `adc_udp_monitor.exe`、Wireshark高负载抓包或其他占用同一数据UDP端口的软件。
- 实时波形用于观察；如需保存数据，请在开始采集前勾选监测页的TXT记录选项并选好路径。取消勾选表示本次不保存。
- TXT以制表符分隔，同时保存原始有符号码值和换算电压（AD7606C ±10 V量程，`V = code × 10 / 32768`）。最终文件在停止采集后生成；TXT可保存超过Excel单张表容量的数据，但导入Excel时每张表最多1,048,576行，更长采集需使用可处理大文件的工具或分段导入。
- 500 kSPS、30组/包的理论值为 16666.67 包/s。状态栏中“接收”与“处理”应持续接近；“队列溢出”必须为0。数包/s的微小差异属于计时窗口量化，不等同于丢包。
- 完整24路、最近5秒高分辨率、30分钟历史与65536包队列会使用约200～300 MB内存；这是保证波形路数和收包稳定性的设计取舍。
- 波形横轴由UDP序号、采样率和每包组数推导；发生丢包时会在对应时间段保留间隔，而不会将后续波形压缩到错误时间位置。
