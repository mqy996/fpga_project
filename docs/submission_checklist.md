# AMD 自主选题赛道提交核对

以下核对依据本地《2026 FPGA 赛道选题指南（AMD）》3.3.3～3.3.5 节，核对日期为 2026-10-31。正式提交时仍需查看报名和上传页面的具体要求。

| 提交内容 | 当前材料与状态 |
| --- | --- |
| 工程源码和可复现构建脚本 | `fpga/`、`qt/`、`build/`；未进入正式闭包的最终工程源码另存于 `reference/` |
| 仿真或验证结果 | `sim/` 包含定向仿真、上位机测试和验证边界；`board/historical_qspi/` 保留既有写入与启动日志 |
| 综合与实现报告 | `fpga/reports/` 中的资源、时序、DRC 等报告对应随包已验证镜像 |
| 上板工程与实测材料 | `fpga/bitstream/`、板卡运行脚本及 `data/` 中的照片、录屏截图和抽检记录 |
| Skill | `skill/` 已整理适用范围、使用方法、验证效果及失效条件；该赛道要求提交 |
| 大模型协作记录 | `report/ai_collaboration/` 收录 6 个案例及 37 段真实对话节录 |
| 设计报告 | `report/design_report.docx`，为 27 页团队视角版本 |
| 开源仓库与许可 | <https://github.com/mqy996/fpga_project>；项目自有内容采用 MIT 许可 |
| 工具版本 | 实际使用 Vivado 2025.1；指南推荐 2026.1 或 2025.2，并允许说明其他版本后提供复现方法 |
| 优化前后性能与资源对比 | 已记录优化过程和当前绝对结果，仍缺同条件的前后量化对照 |
| 视频、队伍信息和上传限制 | 演示视频已剪辑；提交时核对最终文件、队伍信息及页面要求。视频不在本代码包内 |
| 决赛英文海报 | 尚需按 AMD 模板准备一页英文海报，不含队伍信息，A4 彩印并带至现场 |

通用 PYNQ Skill 是额外加分项；本项目提供的是面向 FPGA 采集与验证的技能包。整机模拟精度、功耗和跨 ADC 同步偏差目前尚无统一量化结果，可作为后续补强材料。

本地指南的自主选题部分未给出视频时长、大小和编码格式的具体数值。官网本次核对时访问超时，需以实际提交页面或最新通知为准。赛事官网：<https://www.fpgachina.cn/>。
