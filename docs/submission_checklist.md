# AMD自主选题赛道提交核对

依据本地2026AMD指南3.3.3至3.3.5（印刷20–22页），核对日期2026-10-31。

| 要求 | 本包位置与状态 |
| --- | --- |
| 完整源代码、工程和可复现构建脚本 | fpga/、qt/、build/，额外最终工程源文件保存在reference/ |
| 仿真或验证结果、正确性说明 | sim/、fpga/reports/、board/historical_qspi/ |
| 综合实现资源、时钟与性能 | fpga/reports/，对应已验证镜像，不混用旧release |
| 上板工程、运行和实测输出 | fpga/bitstream/及program_qspi脚本、data/原始图片与记录 |
| Skill | skill/，必交；已包含适用范围、方法、已验证效果和失效条件 |
| 大模型协作记录 | report/ai_collaboration/，6个案例、37段真实公开对话节录；无完整私人会话 |
| 设计报告 | report/design_report.docx，27页团队视角版本 |
| GitHub/Gitee开源及允许再分发许可 | https://github.com/mqy996/fpga_project ，自有代码MIT |
| 工具版本说明 | 实际Vivado2025.1；指南推荐2026.1/2025.2，允许说明其他版本后可复现 |
| 优化前后量化对照 | 现有功能改进和当前绝对数据已保留；尚缺同条件前后量化测量，不编造提升倍数 |
| 模拟精度、跨片同步偏差、功耗 | 既有单片观察与整机量化测量分开，尚无统一整机指标 |
| 视频、报名信息与上传限制 | 用户已有约1分50秒剪辑；本包未选取为最终提交视频，仍需核对上传页面及队伍信息 |
| 决赛英文海报 | 指南印刷25页要求AMD模板一页英文海报、无队伍信息、A4彩印带现场；尚需准备 |

Skill是本赛道必交项，通用PYNQ Skill仅为额外加分。本项目纯RTL技能不冒充PYNQ通用技能。推荐目录结构可调整，但本仓库所有分发路径保持英文小写；README.md与skill入口大小写差异在根readme说明。

指南自主选题部分未给视频时长、文件大小和编码格式的具体数值。官网本轮访问超时，不能把应用赛道3分钟/300M规则移用于FPGA赛道。赛事官网：https://www.fpgachina.cn/ 。
